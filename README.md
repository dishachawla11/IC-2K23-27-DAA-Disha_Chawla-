# Searching and Sorting Algorithms

## Aim
To implement and understand different searching and sorting algorithms.

### Searching Algorithms
1. **Linear Search** – Searches for an element by checking each element one by one.
2. **Binary Search** – Searches for an element by repeatedly dividing a sorted array into halves.

### Sorting Algorithms
3. **Bubble Sort** – Sorts elements by comparing and swapping adjacent elements.
4. **Insertion Sort** – Sorts elements by inserting each element into its correct position.
5. **Selection Sort** – Sorts elements by selecting the smallest element in each pass.
6. **Merge Sort** – Sorts elements using the divide and conquer technique.
7. **Quick Sort** – Sorts elements using a pivot element to divide the array into smaller parts.

## Language Used
C++

## Output
All programs execute successfully and demonstrate the working of searching and sorting algorithms.
